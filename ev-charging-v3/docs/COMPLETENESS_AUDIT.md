## Known limitations (say them yourself in the viva)
* Tested on **MariaDB 10.11**, not on MySQL 8 (the code uses only features MySQL 8.0.16+ has).
* No background job: a CONFIRMED booking whose slot passed stays CONFIRMED (cannot start a session; harmless); an ACTIVE session is not auto-closed (admin can end it).
* Energy kWh is typed in by the user (no real charger hardware); the server only checks it against `power_kw × time left in the slot`.
* Payment is a record created when a session ends (no gateway). Map = link to OpenStreetMap (no embedded map).
* Token is kept in the browser's localStorage and logout only forgets it client-side (stateless JWT, 8 h expiry). No login rate limiting.
* The project has a **single home screen** (station search) rather than a separate "user dashboard"; "My bookings" is the user's dashboard.
* Demo passwords (`harry@123`, `Password@123`) are for the sample data only — change them before publishing a public repo.
